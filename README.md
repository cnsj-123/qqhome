# Closie 衣橱 · v0.1

一个本地优先的私人衣橱与 AI 伙伴 Android App。第一版的数据只储存在手机；相册图片以 URI 引用，不会上传到服务器。

## 已实现

- 已有衣服 / 试过退货两套衣橱
- 单品资料：名称、分类、店铺、价格、购买日、面料、动态尺码、安全类别、评价
- 平铺图、本人与模特参考图
- 穿着与洗涤记录，自动计算单次穿着成本
- OOTD 日历（保存当天搭配后自动增加穿着次数）
- 有性格的衣橱伙伴「小柿」：基于本地衣橱给出评论与关怀

## 手机上构建 APK

把项目上传到 GitHub 的 `main` 分支后，打开仓库 **Actions → Build Android APK**，下载 `closie-debug-apk`，解压并安装其中的 APK。首次安装时请允许浏览器或文件管理器安装未知来源应用。

真实 AI 服务的 API 密钥不会写进仓库；下一步会加入设置页面，以本地加密方式保存。

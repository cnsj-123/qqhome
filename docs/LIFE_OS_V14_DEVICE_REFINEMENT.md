## 改动与反馈对应

### 功能页排序、视觉和滚动

- 删除独立 `ModuleOrderSheet`。在真实模块所在的双列 LazyVerticalGrid 长按抬起，在同一网格中拖动；稳定 module ID 作为 item key，周围模块使用 placement animation 让位。前六个位置继续代表“手边常用”。
- 仅拖动物体有悬浮背景、缩放和小阴影，普通模块使用图标与文字平排，不再给前六项各放一张卡片。
- 长按有一次触觉反馈；靠近上下 56dp 区域时按距离自动滚动；松手后一次性保存到既有 Appearance DataStore。取消手势或第一次返回恢复拖前顺序，写入失败同样回退并提示。TalkBack 自定义操作可逐项前移、后移。底部“恢复默认顺序”清空该 owner 的排序偏好，重新使用标准顺序；拖动结束、取消和保存开始均同步清除壳层取消回调。
- 五个源色参与固定背景渐变；画刷按主题缓存，并置于滚动网格之外。网格使用独立模块 key/contentType，取消原先按“每两项”拼装和标识列表的结构。
- V13 已缓存图标路径，也已使用后台 Finance 投影，这些不是本轮新发现的缺陷。本轮去掉普通模块 Surface 层、降低整页阴影，拖动指针主要在单一悬浮层的 graphicsLayer 阶段读取；没有添加滚动监听重组整页的机制。
- GLASS 在 Android 12+、非 low-RAM 且未关闭动画时，给底下的模块内容施加复用的固定半径 RenderEffect，同时降低背景内容强度。玻璃页 alpha 约 0.68–0.72，保留彩色渐变和清晰前景。旧 Android/low-RAM 通过显著淡化底层文字回退；减少动画设置继续使用 FLAT。

录屏已抽帧检查，但没有帧时间或 GPU 测量。因此这里只能说明减少了哪些成本，不能宣称滚动卡顿已被真机证实消除。玻璃模糊仍需检查低端设备和长时间滑动表现。

### 全局模块切换与 Home

- 壳层统一开放 Home、Finance、衣橱顶层、日历、收件匣、资料库、计划、阅读、普通模块入口及设置的右滑，不在模块里复制抽屉。
- 两侧 24dp 留给系统边缘手势；先辨别方向，竖向滚动和已经消费事件的子控件保留手势所有权。地图/伙伴输入、Appearance、备份及详情编辑路由不开放全局右滑；衣橱内部非顶层、Home 照片查看器、Finance 详情/编辑/日期、导入与自动化页通过壳层 policy 暂停接管。
- 功能页展开时，最后注册的壳层返回处理器优先关闭功能页；若正在排序则先取消排序。不会先触发衣橱等模块自己的返回。
- 选择模块仍直接导航，不等待抽屉关完。仅两个普通模块根路由间免除 NavHost 交叉淡入淡出；设置、备份、详情和编辑路由进出保留 140ms 短淡入淡出，避免全局瞬间替换。
- Home 改成“衬线品牌 + 右侧菜单”首行、副标题、独立伙伴/日历/地图工具行、细分隔、日期和手账内容，保持清楚的两级结构。

### 本地图片主题与字体

- 路径：设置 → 主题与配色 → 从照片或截图取色。使用 Activity Result Photo Picker，适配系统回退；无新增存储权限、网络服务或图片永久副本。
- 在 IO dispatcher 打开临时 URI，先读尺寸、采样到最长边不超过约 256px；最多约 12000 个像素样本，以 RGB 4-bit 分箱聚合。
- 颜色评分综合频率的平方根、色度和明度，第二色按与主色的距离选择，暖色另筛；灰阶、全白、全黑、透明或缺少合适颜色时使用稳定的柔和后备色。纸色向白色混合，主色迭代调整到纸面足够对比度，再交由既有 ThemePalette 生成语义 token。并非直接选出现最多的五个像素。
- 即时预览后可编辑五个 HEX 和名称，另存新主题。最多 24 个命名主题，支持重新选用和删除；JSON 只存在原 Appearance DataStore 的 `namedThemesV1` 中，保存 ID、名称和五色。旧 custom 字段继续保留，仅在集合显示一次“以前的我的配色”；打开编辑器或选用后应用只选择该兼容条目，明确“另存为新主题”并保存才创建副本。旧兼容条目暂不提供删除；五个预置主题保留。无 Room 改动。
- 继续使用打包的 Noto Sans SC 作为 UI/正文和密集 Finance 字体；Noto Serif SC 用于 Home 和功能页的编辑式标题。全局章节标题从 20sp 收到 17sp，正文 14sp/21sp、元信息 12sp/18sp，金融主数字保持专门的 `tnum` 样式。没有依赖 OEM 字体。

### Finance 页面、月历和币种

- 四个局部目的地仍是总览/流水/账户/分析。总览保留本月主卡；余额、辅助入口、流水使用留白与分隔；账户列表用平面行，账户横向速览仍保留卡片；趋势、分类及真实流量改成平面章节。
- 底栏改为 1.45 viewport-unit 描边的轻线图形，使用 Material `LocalContentColor` 跟随选中/未选中颜色，保留 NavigationBarItem 的点击区域和标签。
- 将 UI 中重复生成完整账目投影的工作移入现有后台 state 流，并复用同一次生成的完整流水给详情与未归属调整检查。没有改变 FinanceProjection 或 canonical 写入。
- 流水默认月历入口：月份前后切换、今天、单日点选/取消、整月流水；搜索与账户/分类/标签/性质筛选仍可用。“列表与范围”保留原有日期范围筛选。浏览月份由可恢复的 UI 状态独立记忆，重按流水或从分析返回不重置；明确点击总览“这个月”或月历“今天”才跳到当前月份。单日筛选的标题包含日期、计数仅计算该日显示的流水。
- 日历显示实际收付，不假冒个人净成本：按币种分别累计、转账仅显示存在标记、不计入收支数值。退款/报销真实入账在此按实际收入显示；个人归属分析继续走既有投影。多币种可切换日历展示币种，下方流水保留各币种明细；使用 BigInteger 聚合，避免汇总溢出。大额在日格可能省略，点选日期后可看完整汇总及交易金额。
- 建账提供可搜索、常用币种优先的选择器，仅提供 Core 支持的 0–3 位小数币种。已有任意 canonical entry（包括作废记录）的账户币种锁定；无流水的账户可按原 Repository 规则更改。切换币种不转换或舍入已有输入，精度不合时由原 exact-money 校验报错。转账仍仅同币种，无 FX。

### 自动发现与旧账导入

- 路径：设置 → 账目 · 自动发现与通知。复用原自动化页面，包含总开关、系统通知使用权状态及跳转、微信/支付宝开关、后台确认提醒、现有诊断和规则。
- 总览继续可进入待确认及状态。Notification → Proposal → review → explicit confirm → Truth 保持不变；未修改通知解析、监听、提案或 canonical 确认逻辑。
- XLSX/CSV 文件选择增加常见错误 MIME，并提供“浏览所有文件”回退入口。文件内容仍由原解析器严格识别。明确告知用户无需预建账户，映射阶段可选择既有账户或创建账户；原映射/检查/确认和错误提示继续使用。
- 已在本地检查真实旧账工作簿，以核对异常 dimension 的兼容情况。私有工作簿及其内容、元数据均不提交。**Android picker → stage → mapping → review → commit 仍是真机验收项。** 本轮未执行该端到端流程，也未改写历史 XLSX/CSV 解析器。

# Life OS — Home PRD

**版本：** v0.1  
**状态：** DRAFT  
**日期：** 2026-09-27  
**说明：** 记录 Home 第一轮需求讨论；不是最终 UI 定稿。

## 1. 核心定位
【已确认】首页不是固定 Dashboard 或模块宫格，而是一张会随生活状态变化的**个人生活封面 / 今日手账**。

> 打开以后首先感受到“这是我的生活”，而不是“这是我的管理后台”。

## 2. 双页结构
【已确认】默认打开“今日手账”。从今日手账右滑，进入位于左侧的“功能页”，类似负一页，但不要求传统全屏切换。

```text
← 功能页 │ 今日手账 / Home
          ↑ 默认页
```

今日手账负责生活展示、Plog/美食、回忆、当前事件、柔性提醒、历史回看和导出。  
功能页负责模块入口、高频操作、搜索、快速记录等工具性操作。

功能页具体布局等主要模块讨论后再确定。

## 3. 动态首页
【已确认】首页不是固定模块位。允许进入首页的内容可根据以下因素动态变化：

- 正在发生
- 即将发生
- 最近主动使用
- 最近新记录
- 视觉展示价值
- 回忆价值
- 用户设定的重要程度
- 同类内容近期是否已经展示过多

例如：旅行中提升旅行；临近画画/声乐时浮现对应内容；刚记录书籍时短暂展示；财务只出现适合首页的轻量摘要。

## 4. 模块首页开关
【已确认】设置中，每个可展示模块都有“允许出现在首页”开关。

- 普通模块默认开启。
- 明确私密模块默认关闭。
- 用户开关永远高于推荐算法。

未来如确有需要，可扩展“不显示 / 自动 / 优先显示”，但不是 v0.1 必做。

## 5. Home Surface
【已确认】以后每个业务模块的 PRD 都必须设计 Home Surface，而不是把完整功能页缩小塞到首页。

每个模块必须回答：
1. 什么时候有资格出现在 Home？
2. 展示什么？
3. 有哪些展示形态？
4. 是否包含照片、Live/Motion Photo、视频、声音、地图等？
5. 用户如何校正？
6. 是否进入历史首页？
7. 是否允许导出分享？
8. 空白/缺失/异常如何表现？
9. 是否有隐私限制？

## 6. Life Stack / 生活卡片堆
【已确认方向】首页允许内容像照片一样叠放并左右滑动。同一生活事件可以展示不同切面。

旅行示例：

```text
照片 → 动态照片 → 视频/声音 → 路线 → 景点 → 美食 → 评价
```

油画可以按创作进度滑动；园艺可以展示过去状态到当前开花；Plog 可以组合照片、动态媒体和文字。

点击可放大或进入完整记录。

## 7. 富媒体
【已确认方向】首页可展示照片、Live Photo、Motion Photo、视频、声音、地图/路线等。静态画面可在交互后播放动态内容及声音。

首页引用统一 Media 数据，不为首页重复复制原始媒体。

## 8. Plog / 美食
【已确认】Plog 和美食非常适合成为首页视觉内容。当天拍摄/记录后可以进入今日手账。Plog 与 Food 的领域关系后续单独讨论。

## 9. 柔性待办
【已确认】提醒可以进入首页，但不能把 Home 变成强制任务管理器。

> Life OS 可以提醒，但不审判用户。

未完成就是未完成，不使用惩罚式逾期设计。提醒可表现为浮在生活封面上的信件、便笺或轻量通知。

提醒强度可从“安静出现 → 提升位置 → 明显强调 → 极少数时间敏感事件的动态提醒”逐渐增强。红字、抖动、呼吸动画等仅为 UI 候选，尚未确认。

## 10. 回忆
【已确认】首页承担回望生活的功能，可以出现几个月前、去年的今天、旧旅行、旧照片、过去的作品/植物/阅读等，并可点击进入原记录。

## 11. 时间距离
【已确认方向】首页可偶尔展示：
- 距离旅行还有 12 天
- 这盆花已经陪伴 326 天
- 距离上次画画 41 天
- 一年前的今天开始读这本书

必须克制使用，不能成为持续提醒轰炸。

## 12. 空白日
【已确认】没有新记录是正常状态，不强制填满。

可以显示“今日无事发生”，配合大量留白；仍可出现历史回忆、去年的今天、未来事件倒计时。若无合适内容，也允许真正安静。

## 13. 日历与历史首页
【已确认】首页有日历入口，可以选择过去日期并回看那一天的 Life OS 首页，体验目标是“翻阅过去的生活封面”。

历史首页不复制原始照片/视频，可保存轻量编排信息并引用原始数据。

【待技术设计】历史首页究竟保存当时精确编排、用当前 UI 重渲染，还是混合方案，后续决定。

## 14. 人工校正
【已确认】采用“系统编排 + 用户适度校正”。

用户可以换掉系统选得不好的照片、隐藏不喜欢的内容、暂时保留特别喜欢的内容等，但不能演变成复杂网页装修器。调整首页不得修改原始业务事实。

## 15. 隐私
【已确认】明确私密模块默认不上首页。

“允许上首页”和“允许导出分享”是两个独立概念。

## 16. 今日手账 / 长图导出
【已确认】首页提供“今日手账 / 生活长图”导出，不局限于截图，可针对分享重新排版。

流程：

```text
导出 → 选择允许进入导出的模块/内容 → 生成预览 → 用户确认 → 导出
```

财务、健康、私密文字等不得因为曾在首页出现就自动进入分享结果。

## 17. 多用户适应
【已确认】未来可能给朋友等其他用户使用，因此不能假定每个人使用相同模块。

> 功能存在 ≠ 用户必须使用 ≠ 首页必须展示。

## 18. 与导航的边界
【已确认】“模块是什么”“模块从哪里进入”“模块怎样出现在首页”分开设计。Home Surface 不冻结最终顶层导航。

## 19. 展示与效率的边界
【已确认】今日手账可以大胆追求视觉和生活感；工具效率交给相邻功能页，避免为了快捷把首页塞满按钮。

## 20. 当前非目标
v0.1 不冻结：
- 最终视觉稿、字体、颜色
- 动画参数和卡片尺寸
- 功能页最终布局
- 顶层导航
- 复杂 AI 推荐算法
- 导出模板数量

也不要求每个模块每天都产生首页内容。

## 21. 第一轮验收标准
- 默认页具有生活封面感而非 Dashboard 感。
- 今日手账与工具入口分层。
- 可横向快速进入功能页。
- 普通模块可单独关闭 Home Surface。
- 私密模块默认不上首页。
- 支持动态生活内容、Plog/美食、回忆、柔性待办和空白日。
- 支持日历回看。
- 支持替换/隐藏系统选择的首页内容。
- 支持带内容筛选和预览的生活长图导出。
- 首页媒体不重复保存原件。
- 未完成任务没有惩罚式展示。
